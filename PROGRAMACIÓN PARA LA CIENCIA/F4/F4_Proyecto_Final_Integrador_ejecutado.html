I. Introducción y contextualización¶

La gestión de activos industriales críticos requiere anticipar eventos de falla que puedan afectar la continuidad operacional, la disponibilidad de equipos y la eficiencia del proceso productivo. En este contexto, el mantenimiento predictivo permite utilizar datos históricos y métricas operacionales para identificar señales tempranas de comportamiento anómalo.

El proyecto se orienta al análisis de un dataset de mantenimiento predictivo compuesto por registros temporales, identificadores de dispositivos, una variable objetivo de falla (failure) y métricas operacionales representadas como sensores o variables de condición (metric1, metric2, etc.). A partir de estos datos, las fases previas permitieron definir la problemática, limpiar y transformar el dataset, implementar soluciones algorítmicas, validar código y construir una arquitectura modular.

La Fase 4 consolida el trabajo transversal mediante un notebook integrador que conecta la definición del problema, el dataset procesado, el núcleo algorítmico, la arquitectura orientada a objetos y un conjunto de visualizaciones analíticas. Las nuevas visualizaciones permiten comunicar patrones relevantes asociados a eventos de falla, distribución de métricas operacionales, desbalance de la variable objetivo y relaciones entre sensores.

Es importante precisar que el proyecto no calcula formalmente el OEE completo, ya que no se dispone de todas las variables necesarias para estimar disponibilidad, rendimiento y calidad. Sin embargo, el análisis se vincula directamente con la dimensión de disponibilidad operacional, dado que los eventos de falla afectan la continuidad productiva y pueden reducir el desempeño global de los activos.

II. Definición de la problemática y objetivos¶

Problemática¶

Las fallas en activos industriales suelen ser eventos poco frecuentes, pero de alto impacto operacional. Su ocurrencia puede generar detenciones no planificadas, pérdida de disponibilidad, incremento de costos de mantenimiento y reducción de la eficiencia del proceso productivo. Desde una perspectiva de ciencia de datos, este tipo de problema presenta desafíos particulares: desbalance extremo de clases, alta variabilidad en las métricas operacionales y dificultad para explicar las fallas mediante una sola variable aislada.

En el dataset analizado, la variable objetivo failure representa la ocurrencia o no ocurrencia de una falla. La baja proporción de eventos positivos confirma que se trata de un fenómeno de eventos raros. Esto obliga a interpretar los resultados con cautela y a considerar, en etapas futuras de modelamiento, métricas distintas a Accuracy, tales como Recall, Precision y F1-Score.

Objetivo general¶

Diseñar e implementar un flujo analítico reproducible en Python para estudiar eventos de falla en activos industriales críticos, integrando preprocesamiento, validación técnica, análisis algorítmico, arquitectura modular y visualizaciones orientadas a la comunicación de resultados.

Objetivos específicos¶

  • Consolidar un dataset procesado, validado y trazable para análisis posterior.
  • Implementar componentes funcionales y orientados a objetos que organicen el flujo de análisis.
  • Evaluar la eficiencia de soluciones algorítmicas mediante mediciones reproducibles con timeit.
  • Construir visualizaciones analíticas que permitan interpretar el desbalance de fallas, la distribución de métricas y la relación entre sensores.
  • Comunicar hallazgos técnicos de forma clara para apoyar futuras decisiones de mantenimiento predictivo.
  • Declarar explícitamente los límites del análisis respecto al cálculo formal del OEE.

import pandas as pd
import numpy as np

class Preprocesador:
    """Clase derivada encargada de aplicar procesos de limpieza y transformación de datos."""
    def __init__(self, df):
        self._df = df.copy()
        
    def obtener_datos(self):
        return self._df

class Transformador(Preprocesador):
    """Clase derivada encargada de aplicar procesos de limpieza y transformación de datos."""
    def __init__(self, df):
        super().__init__(df)
        
    def imputar_nulos(self):
        self._df = self._df.dropna()
        return self
        
    def escalar_minmax(self, columna):
        val_min = self._df[columna].min()
        val_max = self._df[columna].max()
        if val_max != val_min:
            self._df[columna] = (self._df[columna] - val_min) / (val_max - val_min)
        return self

class VisualizadorF4:
    """
    Clase responsable de cargar, validar y preparar datos para las visualizaciones
    analíticas de la Fase 4 del proyecto integrador.
    """

    def __init__(self):
        self._df = self._cargar_dataset()
        self._validar_dataset()

    def _cargar_dataset(self):
        rutas_posibles = [
            Path("data/processed/dataset_procesado.csv"),
            Path("../data/processed/dataset_procesado.csv")
        ]

        for ruta in rutas_posibles:
            if ruta.exists():
                df = pd.read_csv(ruta, parse_dates=["date"])
                print(f"Dataset cargado desde: {ruta}")
                return df

        raise FileNotFoundError(
            "No se encontró el archivo data/processed/dataset_procesado.csv. "
            "Ejecutar primero la Fase 2 o verificar la estructura del repositorio."
        )

    def _validar_dataset(self):
        columnas_requeridas = {"date", "device", "failure", "metric1"}
        faltantes = columnas_requeridas - set(self._df.columns)

        if faltantes:
            raise ValueError(f"Faltan columnas requeridas para F4: {faltantes}")

        assert not self._df.empty, "El dataset no debe estar vacío."
        assert self._df["failure"].isin([0, 1]).all(), "La variable failure debe ser binaria."
        assert self._df["device"].notna().all(), "Existen dispositivos sin identificador."

    def obtener_datos(self):
        return self._df.copy()

    def resumen_base(self):
        return {
            "Total registros analizados": len(self._df),
            "Total eventos de falla": int(self._df["failure"].sum()),
            "Total dispositivos únicos": int(self._df["device"].nunique())
        }

    def fallas_por_mes(self):
        df_fallas = self._df[self._df["failure"] == 1].copy()

        return (
            df_fallas
            .assign(mes=df_fallas["date"].dt.to_period("M").astype(str))
            .groupby("mes")
            .size()
            .sort_index()
        )

    def fallas_por_dispositivo(self):
        return (
            self._df[self._df["failure"] == 1]
            .groupby("device")
            .size()
            .sort_values(ascending=False)
        )

    def distribucion_reincidencia(self):
        return (
            self.fallas_por_dispositivo()
            .value_counts()
            .sort_index()
        )

    def datos_metric1_log(self):
        df_temp = self._df.copy()
        df_temp["metric1_log"] = np.log1p(df_temp["metric1"])
        return df_temp

class VisualizadorAnaliticoF4:
    """
    Clase responsable de cargar, validar y preparar datos para las
    visualizaciones analíticas avanzadas de la Fase 4.
    """

    def __init__(self):
        self._df = self._cargar_dataset()
        self._validar_dataset()
        self._metricas = self._detectar_metricas()
        self._preparar_variables()

    def _cargar_dataset(self):
        rutas_posibles = [
            Path("data/processed/dataset_procesado.csv"),
            Path("../data/processed/dataset_procesado.csv")
        ]

        for ruta in rutas_posibles:
            if ruta.exists():
                df = pd.read_csv(ruta, parse_dates=["date"])
                print(f"Dataset cargado desde: {ruta}")
                return df

        raise FileNotFoundError(
            "No se encontró data/processed/dataset_procesado.csv. "
            "Verificar que el dataset procesado de Fase 2 exista en el repositorio."
        )

    def _validar_dataset(self):
        columnas_requeridas = {"date", "device", "failure", "metric1"}
        faltantes = columnas_requeridas - set(self._df.columns)

        if faltantes:
            raise ValueError(f"Faltan columnas requeridas para Fase 4: {faltantes}")

        assert not self._df.empty, "El dataset no debe estar vacío."
        assert self._df["failure"].isin([0, 1]).all(), "La variable failure debe ser binaria."
        assert self._df["device"].notna().all(), "Existen dispositivos sin identificador."

    def _detectar_metricas(self):
        metricas = [
            col for col in self._df.columns
            if col.startswith("metric") and pd.api.types.is_numeric_dtype(self._df[col])
        ]

        if len(metricas) == 0:
            raise ValueError("No se detectaron columnas numéricas tipo metric.")

        return metricas

    def _preparar_variables(self):
        self._df["estado_falla"] = self._df["failure"].map({
            0: "Sin falla",
            1: "Falla"
        })

        self._df["estado_falla"] = pd.Categorical(
            self._df["estado_falla"],
            categories=["Sin falla", "Falla"],
            ordered=True
        )

    @staticmethod
    def _log1p_seguro(serie):
        serie = pd.to_numeric(serie, errors="coerce")
        minimo = serie.min(skipna=True)

        if pd.notna(minimo) and minimo < 0:
            serie = serie - minimo

        return np.log1p(serie)

    @staticmethod
    def _limpiar_ejes(ax):
        ax.spines["top"].set_visible(False)
        ax.spines["right"].set_visible(False)
        ax.grid(axis="y", alpha=0.25)
        ax.set_axisbelow(True)
        return ax

    def resumen(self):
        return {
            "Total registros analizados": len(self._df),
            "Total eventos de falla": int(self._df["failure"].sum()),
            "Total registros sin falla": int((self._df["failure"] == 0).sum()),
            "Total dispositivos únicos": int(self._df["device"].nunique()),
            "Métricas numéricas detectadas": ", ".join(self._metricas)
        }

    # ============================================================
    # 1. Gráfico de barras de distribución de variable objetivo
    # ============================================================

    def grafico_variable_objetivo(self):
        conteo = (
            self._df["estado_falla"]
            .value_counts()
            .reindex(["Sin falla", "Falla"], fill_value=0)
        )

        datos = conteo.rename_axis("Estado").reset_index(name="Registros")
        datos["Porcentaje"] = datos["Registros"] / len(self._df) * 100

        fig, ax = plt.subplots(figsize=(8, 4))

        sns.barplot(
            data=datos,
            x="Estado",
            y="Registros",
            palette="Set1",
            ax=ax
        )

        ax.set_title("Distribución de la variable objetivo: falla vs no falla")
        ax.set_xlabel("Estado operacional")
        ax.set_ylabel("Cantidad de registros")

        # Escala logarítmica para que la clase minoritaria sea visible
        if (datos["Registros"] > 0).all():
            ax.set_yscale("log")
            ax.set_ylabel("Cantidad de registros (escala log)")

        for barra, (_, fila) in zip(ax.patches, datos.iterrows()):
            altura = barra.get_height()
            ax.annotate(
                f"{int(fila['Registros']):,}\n({fila['Porcentaje']:.3f}%)",
                xy=(barra.get_x() + barra.get_width() / 2, altura),
                xytext=(0, 5),
                textcoords="offset points",
                ha="center",
                va="bottom",
                fontsize=9
            )

        self._limpiar_ejes(ax)
        plt.tight_layout()
        plt.show()

    # ============================================================
    # 2. Histograma con KDE
    # ============================================================

    def grafico_histograma_kde(self, metrica="metric1"):
        if metrica not in self._metricas:
            metrica = self._metricas[0]

        df_plot = self._df[[metrica, "estado_falla"]].dropna().copy()
        metrica_log = f"{metrica}_log1p"
        df_plot[metrica_log] = self._log1p_seguro(df_plot[metrica])

        fig, ax = plt.subplots(figsize=(10, 4))

        sns.histplot(
            data=df_plot,
            x=metrica_log,
            hue="estado_falla",
            kde=True,
            stat="density",
            common_norm=False,
            palette="muted",
            alpha=0.35,
            ax=ax
        )

        ax.set_title(f"Distribución de {metrica} con transformación log1p y KDE")
        ax.set_xlabel(f"{metrica} transformada con log1p")
        ax.set_ylabel("Densidad")

        self._limpiar_ejes(ax)
        plt.tight_layout()
        plt.show()

    # ============================================================
    # 3. Scatter plot con hue
    # ============================================================

    def grafico_scatter_hue(self):
        if len(self._metricas) < 2:
            print("No se genera scatter plot: se requieren al menos dos métricas numéricas.")
            return

        metrica_x = self._metricas[0]
        metrica_y = self._metricas[1]

        df_plot = self._df[[metrica_x, metrica_y, "failure", "estado_falla"]].dropna().copy()

        df_plot[f"{metrica_x}_log1p"] = self._log1p_seguro(df_plot[metrica_x])
        df_plot[f"{metrica_y}_log1p"] = self._log1p_seguro(df_plot[metrica_y])

        # Muestra controlada para evitar sobrecarga visual:
        # se mantienen todas las fallas y se toma muestra de registros sin falla.
        df_falla = df_plot[df_plot["failure"] == 1]
        df_normal = df_plot[df_plot["failure"] == 0].sample(
            n=min(5000, (df_plot["failure"] == 0).sum()),
            random_state=42
        )

        df_scatter = pd.concat([df_normal, df_falla], axis=0)

        fig, ax = plt.subplots(figsize=(10, 5))

        sns.scatterplot(
            data=df_scatter,
            x=f"{metrica_x}_log1p",
            y=f"{metrica_y}_log1p",
            hue="estado_falla",
            palette="Set1",
            alpha=0.55,
            s=35,
            ax=ax
        )

        ax.set_title(f"Relación entre {metrica_x} y {metrica_y} según condición de falla")
        ax.set_xlabel(f"{metrica_x} transformada con log1p")
        ax.set_ylabel(f"{metrica_y} transformada con log1p")
        ax.legend(title="Estado")

        self._limpiar_ejes(ax)
        plt.tight_layout()
        plt.show()

    # ============================================================
    # 4. Gráfico de violín
    # ============================================================

    def grafico_violin(self, metrica="metric1"):
        if metrica not in self._metricas:
            metrica = self._metricas[0]

        df_plot = self._df[[metrica, "estado_falla"]].dropna().copy()
        metrica_log = f"{metrica}_log1p"
        df_plot[metrica_log] = self._log1p_seguro(df_plot[metrica])

        fig, ax = plt.subplots(figsize=(8, 4))

        sns.violinplot(
            data=df_plot,
            x="estado_falla",
            y=metrica_log,
            palette="muted",
            inner="quartile",
            cut=0,
            ax=ax
        )

        ax.set_title(f"Distribución de {metrica} según condición de falla")
        ax.set_xlabel("Estado operacional")
        ax.set_ylabel(f"{metrica} transformada con log1p")

        self._limpiar_ejes(ax)
        plt.tight_layout()
        plt.show()

    # ============================================================
    # 5. Matriz de correlación
    # ============================================================

    def grafico_heatmap_correlacion(self):
        columnas_corr = self._metricas + ["failure"]

        if len(columnas_corr) < 3:
            print("No se genera heatmap: se requieren al menos dos métricas más la variable failure.")
            return

        corr = self._df[columnas_corr].corr(numeric_only=True)

        fig, ax = plt.subplots(figsize=(10, 7))

        sns.heatmap(
            corr,
            annot=True,
            fmt=".2f",
            cmap="coolwarm",
            center=0,
            linewidths=0.5,
            ax=ax
        )

        ax.set_title("Matriz de correlación entre métricas operacionales y variable de falla")
        plt.tight_layout()
        plt.show()

Interpretación ejecutiva de visualizaciones analíticas avanzadas¶

1. Distribución de la variable objetivo failure.
El gráfico de barras evidencia el desbalance extremo entre registros normales y eventos de falla. Este hallazgo es central, porque demuestra que Accuracy puede ser una métrica engañosa en un futuro modelo predictivo. Un modelo que clasifique casi todo como “sin falla” podría obtener alta exactitud, pero sería poco útil para detectar eventos críticos. Por ello, futuras etapas deberían considerar Recall, Precision y F1-Score.

2. Histograma con KDE.
El histograma con curva de densidad permite analizar la distribución de una métrica operacional. La transformación log1p facilita la lectura cuando existen escalas amplias o valores extremos. La presencia de dispersión y asimetrías indica que no se debe asumir normalidad sin revisión previa.

3. Scatter plot con codificación por color.
El gráfico de dispersión permite observar si las fallas se concentran en una zona específica al combinar dos sensores. Si las fallas aparecen dispersas en la nube general, se refuerza la necesidad de un enfoque multivariable más avanzado.

4. Gráfico de violín.
El gráfico de violín compara la distribución de una métrica entre operación normal y falla. Permite observar diferencias de mediana, dispersión y concentración de valores. Si las formas son similares, la métrica no discrimina claramente por sí sola; si son distintas, puede aportar señal para modelos posteriores.

5. Matriz de correlación.
El heatmap permite revisar relaciones lineales entre sensores y detectar posibles redundancias. Si failure no presenta una correlación fuerte con una única métrica, se justifica técnicamente la necesidad de modelos que integren varias señales operacionales.

En conjunto, estas visualizaciones confirman que el problema presenta eventos raros, alta variabilidad en métricas operacionales y necesidad de análisis multimétrica.
