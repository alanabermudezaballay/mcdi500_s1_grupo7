# Fase 2 — Preprocesamiento y transformación del dataset

Esta carpeta documenta la Fase 2 del proyecto transversal MCDI500.

El notebook oficial de esta fase se mantiene en:

`notebooks/F2_Preprocesamiento.ipynb`

## Propósito de la Fase 2

La Fase 2 permitió cargar, revisar, limpiar, transformar y validar el dataset de mantenimiento predictivo utilizado en el proyecto.

## Resultado principal

El resultado central fue la generación del archivo procesado:

`data/processed/dataset_procesado.csv`

Este dataset validado se reutiliza como insumo para las fases F3 y F4.

## Relación con el proyecto final

Esta fase asegura que el análisis algorítmico, las visualizaciones y la comunicación de resultados se construyan sobre una base de datos limpia, trazable y reproducible.
