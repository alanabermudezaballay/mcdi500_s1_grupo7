# Fase 1 — Definición del problema y entorno reproducible

Esta carpeta documenta la Fase 1 del proyecto transversal MCDI500.

El notebook oficial de esta fase se mantiene en:

`notebooks/F1_Definicion.ipynb`

## Propósito de la Fase 1

La Fase 1 permitió definir la problemática del proyecto, contextualizar el objetivo general, caracterizar inicialmente el dataset y establecer una base reproducible de trabajo mediante Python, Jupyter Notebook, Git y GitHub.

## Relación con el proyecto final

Esta fase aporta la definición del problema asociado a la optimización del OEE mediante mantenimiento predictivo inteligente en activos críticos industriales. Sus resultados sirven como punto de partida para las fases posteriores de preprocesamiento, diseño algorítmico, visualización e integración final.
